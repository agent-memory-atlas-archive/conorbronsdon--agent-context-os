# Context OS v0.15.0

Hermes Agent and Cursor CLI join Claude Code, Codex, OpenClaw, and OpenCode as
first-class lifecycle hosts. Both adapters have installed-client evidence for
setup, read-only start, checkpoint, and session close, with reviewed proposals,
exact-digest apply, receipts, and rejection controls.

## What changed

- Hermes Agent v0.21.5 (2026.9.24) completed the lifecycle on Windows with
  Gemini 3.8 Flash through OpenRouter. Instruction delivery is checked in a
  separate tool-free turn before normal lifecycle execution. Native Hermes
  memory stays separate from repository state; optional hooks remain advisory.
- Cursor Agent CLI 2026.09.28-64d2043 completed the lifecycle and a fresh-session
  continuity check on Windows. Its conformance runner records reviewed apply,
  rejection controls, and unchanged unrelated files. Doctor probes the
  `cursor-agent` executable separately from the desktop IDE.
- An ACP protocol foundation adds offline coverage for request correlation,
  streamed notifications, cancellation, and refusal of permission requests.
  Bounded live Cursor/T3 and Hermes smoke tests record read and explicit-skill
  behavior. They do not establish full ACP lifecycle support.
- Pi Dash is an optional experimental catalog entry with pinned-source evidence
  for its data flows, installation effects, and approval limits. Context OS
  does not install it.
- Onboarding and draft announcement copy explain reviewed Git-backed handoffs
  and distinguish branch support from released support.

## Support boundaries

Cursor IDE and Devin remain experimental. Cursor wrote files without requesting
permission in both T3 Supervised mode and a direct ACP test; those failed
controls are retained. Connecting a first-class CLI through an app does not
automatically promote that app integration.

Hermes lifecycle evidence uses explicit skill preloading. A separate interactive
probe verifies routing for all four `/context-*` commands. Short
`/start` and `/update` aliases collide with Hermes built-ins; use the documented
`/context-*` commands. First-class support does not imply blocking hooks,
host execution authorization, or shared native memory.

The recorded versions and platforms bound these claims. Review the
[promotion evidence](https://github.com/conorbronsdon/agent-context-os/blob/1d5f0dfa590cfd189128169d1aace00526442993/docs/evidence/runtime-promotion-2026-09-29/README.md) and each
adapter guide for reproduction steps and limitations.

From the published immutable release, download all five attached assets. Start
with `agent-context-os-template-v0.15.0.OFFLINE-VERIFY.md`; the canonical template
is `agent-context-os-template-v0.15.0.tar`.
